# Local interface fonts

Instrument Serif regular and Ostrich Sans bold supply the current editorial headings/prose and interface labels through next/font/local. IBM Plex Mono400/500 supplies technical evidence/SQL/IDs. The historical Outfit variable400-700 asset is retained but no longer loaded by the root layout. All bundled faces have their upstream SIL Open Font License notices alongside the assets; keep those notices when redistributing. sources.json and landing-sources.json retain exact source URLs, binary/license SHA-256 values and byte counts. Active fonts use swap and system fallbacks, are served from the application origin, and make no runtime third-party font request. Non-Latin glyphs use system fallbacks.
