# Local interface fonts

Outfit variable400-700 and IBM Plex Mono400/500 Latin WOFF2 assets are bundled for next/font/local. Only Outfit is preloaded; all fonts use swap and system fallbacks. They are licensed under the included SIL Open Font License texts from the Google Fonts source repository. sources.json retains source URLs, exact binary SHA-256 values and byte counts. Fonts are served from the application origin, with no runtime third-party font request. Non-Latin glyphs use system fallback fonts.
