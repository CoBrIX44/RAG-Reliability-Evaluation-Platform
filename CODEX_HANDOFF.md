## Source and scoring conventions
Canonical section offsets count Unicode code points, start-inclusive/end-exclusive. Document-global offsets address section text joined by two newlines. Browser selection translates UTF-16 to code points. Gold groups accept alternative sets of spans; every span in one alternative is required. Candidate edits clear the UI review flag; publication requires explicit named review, topic/split/group/reference facts/evidence. Split groups and source sections cannot straddle development/test.

Fixed chunk windows cross sections only within one document revision. Section chunking preserves section boundaries and splits oversized sections. Both use original offset mappings, exact source text slices, bounded token counts/overlap, deterministic IDs, and canonical/chunk-local span maps. Tokenizer normalization never replaces canonical text. The SQL boundary verifies source membership and substring equality and rejects null/noninteger/unordered chunk annotations.

Pinned tokenizer: sentence-transformers/all-MiniLM-L6-v2 at 1110a243fdf4706b3f48f1d95db1a4f5529b4d41. tokenizer.json SHA-256 be50c3628f2bf5bb5e3a7f17b1f74611b2561a3a27eeab05e5aa30f411572037; tokenizers 0.23.3; huggingface-hub 1.33.0. Load offline by default; the worker explicitly prepares the public tokenizer cache on first build. No Hub token is sent. Special tokens, repository padding, and truncation are disabled for source tokenization. Index manifests freeze config, corpus hash, tokenizer identity/hash, and chunk hash/count. Dense manifests additionally freeze the embedding contract/artifacts/runtime.

Lexical search: English plainto_tsquery, ts_rank_cd normalization 0, stable ordinal/ID ties; PostgreSQL full-text ranking, not BM25. API preview is bounded to 50 passages and 8192 context tokens; UI returns top five. Packed context retokenizes combined text/separators, deduplicates identical chunk IDs, clips the first oversized source prefix, then stops. Truncated/omitted passages are reported. This is a document-text budget; future generation must account for prompt overhead.

Scoring canonical-group-union-v1 merges canonical intervals without duplicate coverage inflation. Recall requires every span in any accepted alternative. Passage precision requires at least one full accepted span. Empty applicable retrieval is zero; unanswerable cases are not applicable; missing annotations are unavailable. Scores are independently tested but are not yet connected to saved runs. Lexical scores shown in the preview are not accuracy metrics.
